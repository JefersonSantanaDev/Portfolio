Portfólio profissional desenvolvido para apresentar minhas habilidades, projetos e experiência como **Front-End Developer**. Design minimalista com foco em performance e acessibilidade.

### ✨ Características

- 🎨 Design Minimalista - Interface moderna preto e branco
- 🌓 Tema Claro/Escuro - Alternância suave entre modos
- 📱 100% Responsivo - Adaptável a todos os dispositivos
- ⚡ Performance Otimizada - Carregamento rápido
- 📬 Formulário de Contato - Integrado com Formspree

## 🛠️ Instalação

```bash
# Clone o repositório
git clone https://github.com/JefersonSantanaDev/Portfolio.git
cd Portfolio

# Instale as dependências
npm install

# Execute em modo desenvolvimento
npm run dev

# Abra index.html no navegador
```

O comando `npm run dev` inicia o Tailwind CSS em modo watch para compilar automaticamente as mudanças.
